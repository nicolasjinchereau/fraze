# Fraze Syntax Highlighting

Basic TextMate grammar for the **Fraze** language.

## Install (dev)
1. Open this folder in VS Code.
2. Run: `npm i -g vsce` (optional if you want a VSIX).
3. Press `F5` to launch the Extension Development Host.
4. Open a `.fz` file and verify highlighting.

## Packaging
```
vsce package
```
This produces `fraze-syntax-1.0.0.vsix` you can install via the Extensions view (⋯ → Install from VSIX).
